# 🧔 Recep İvedik: Hand Gesture Recognition Engine

**Recep Ivedik Engine** is a real-time computer vision application that detects specific hand gestures using your webcam and dynamically displays corresponding pop-culture images & memes based on spatial landmark physics. 

Built with Python, OpenCV, and Google's MediaPipe framework.

---

## 🚀 Features

- **Real-Time Hand Tracking:** Ultra-fast 21-point hand landmark localization.
- **Custom Spatial Heuristics:** Advanced Euclidean coordinate logic for precise gesture detection (claws, pointing, call gestures, etc.).
- **Dynamic Image Overlay:** Smooth real-time image rendering on top of the webcam feed.
- **Fallback State:** Default standby overlay when no specific gesture is performed.

---

## 🛠️ Tech Stack

- **Python 3.x**
- **OpenCV (`opencv-python`):** Frame capture, matrix operations, and image rendering.
- **MediaPipe (`mediapipe`):** Machine learning pipeline for hand landmark detection.
