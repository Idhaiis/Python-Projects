# DVD Screensaver

A simple DVD logo bouncing simulation written with Pygame.

## What It Does

* Bounces the `w.png` image around the screen, you can change whatever image you want.
* Runs in fullscreen and hides the mouse cursor.
* Press the ESC key to exit.

## Installation and Running

1. Install Pygame:
    ```bash
    pip install pygame
2. Run the script:

    ```bash
    python main.py
